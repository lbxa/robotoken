# Robotoken report

**What Would a GPT-3-Scale Robotics Dataset Cost?**  
Lucas · 29 September 2026 · https://robotoken.lbxa.net

`robotoken.tex` is the authoritative, self-contained manuscript. It includes its bibliography, the Matplotlib-generated PGF figure, and the arXiv-style package with its MIT license notice. No other source file is required to compile it. `robotoken.pdf` is the publication PDF.

## Editing and building

Open `robotoken.tex` in Codex's built-in LaTeX editor for editing and PDF preview. The editor can compile this single source without a local TeX installation.

To export a PDF with an existing TeX Live / MacTeX installation, run:

```sh
make -C report
```

From inside this directory, use `make`. This runs LaTeX and BibTeX, places intermediate files in `build/`, and copies the final PDF to the website's downloads. The editable LaTeX source stays in this directory and is not published on the website. The Makefile requires `latexmk` and `bibtex`.

`plot_scales.py` is the editable Matplotlib source for the figure. It declares its dependencies and preserves the manuscript's measurements and scenario inputs. Generate its vector and raster outputs with:

```sh
uv run report/plot_scales.py
```

This writes desktop/mobile SVG and PNG assets to the website and `figures/scales-cost.pgf` for LaTeX. After changing the plot, copy the generated PGF into the existing `PYPLOT TOKEN REGIMES` block in `robotoken.tex`, then compile the existing manuscript. Embedding this generated geometry keeps the built-in editor independent of external figure files. Update both captions if visual encodings change.

The web edition is directly authored in `../website/src/content/sections/`; keep it aligned when changing the manuscript. The website's separate `robotoken.bib` cites this report, while the research bibliography remains embedded in the LaTeX source.

## Attribution

The embedded style derives from [George Kour's arxiv-style](https://github.com/kourgeorge/arxiv-style), used under the MIT license preserved in the source. The style is a preprint layout; it does not imply acceptance or registration by arXiv.
