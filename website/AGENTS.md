# Robotoken website

This is the Astro research website for Robotoken at `https://robotoken.lbxa.net`.

## Commands

Run commands from `website/` using Bun: `bun install`, `bun run dev`, `bun run build`, `bun run typecheck`, and `bun run lint`.

`bun run deploy:check` builds the site and validates the Wrangler deployment without publishing. `bun run deploy` builds and publishes `dist/` to Cloudflare Workers and the custom domain configured in `wrangler.jsonc`. Confirm the authenticated Cloudflare account with `bunx wrangler whoami` before a real deployment. These commands use the existing PDF in `public/files/`; rebuild the report separately when its source changes.

## Content

- The authoritative, self-contained LaTeX manuscript is `../report/robotoken.tex`.
- `src/content/sections/*.mdx` is the full web edition, ordered by frontmatter. Every section needs a stable `slug`; all except the abstract need a `title`.
- `src/pages/index.astro` owns hero metadata, artifact links, the contents list, and section rendering.
- `public/files/` holds the current report PDF and BibTeX citation. Keep the LaTeX source in `../report/`; do not publish a source download.
- `public/figures/scales-cost.svg` and `scales-cost-mobile.svg` are generated by `../report/plot_scales.py` with Matplotlib. The report embeds the corresponding generated PGF; keep the report and website figure captions synchronized with the visual encodings.
- Preserve the original research template's styling and spacing exactly: infinity SVG, header metadata, title rules, typography, author and button spacing, content widths, section gaps, and single-column table of contents. Only project details and report content vary between research projects. Do not add a wordmark or metric strip to the template.
- Keep equations and tables accessible on narrow screens without changing the template's typography or spacing.

## Scientific and publication constraints

Preserve the distinction between scenario assumptions and measured evidence. The 2T target is an illustrative stress assumption, not GPT-3's historical training budget or a validated robotics capability threshold. Costs are in constant 2026 US dollars and exclude training compute. Keep all tables and caveats synchronized with the manuscript.

Use Lucas Barbosa as the author and NYU as the affiliation, as explicitly supplied by the author. The report is a preprint without an assigned arXiv identifier. Do not add departments or other affiliations from the site's former template. Update the nearest README changelog when durable project decisions change.
