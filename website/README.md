# Robotoken website

Research website for **What Would a GPT-3-Scale Robotics Dataset Cost?**, a preprint by Lucas Barbosa (NYU). Production URL: https://robotoken.lbxa.net.

The Astro site retains the original template's quiet academic layout. Ordered MDX sections contain the full report narrative, equations, assumptions, tables, references, and citation. The authoritative manuscript is `../report/robotoken.tex`.

## Development

Run from this directory:

```sh
bun install
bun run dev
bun run build
bun run typecheck
bun run lint
```

## Content and publication

- `src/pages/index.astro`: title, author, project metadata, downloads, and contents.
- `src/content/sections/`: manually authored web edition of the manuscript. Keep numerical assumptions and scientific caveats aligned with the report.
- `public/figures/scales-cost.svg` and `scales-cost-mobile.svg`: vector Matplotlib figures for desktop and narrow screens, generated by `../report/plot_scales.py` from the same data and cost equations as the report. PNG copies are also available.
- `public/files/robotoken.pdf`: the downloadable report. LaTeX source remains in `../report/` and is not published on the website.
- `public/files/robotoken.bib`: citation imported by the copyable BibTeX widget.
- `astro.config.ts` and `wrangler.jsonc`: canonical URL and Cloudflare static-assets configuration for `robotoken.lbxa.net`.

Build the report with `make -C ../report` before the website; this refreshes the PDF download. Run `uv run ../report/plot_scales.py` when changing the figure, and update the manuscript's embedded PGF block as described in the report README. A website build produces `dist/`; it does not deploy the site or change DNS.

## Deploy to Cloudflare

Run from `website/` after `bun install`:

```sh
bun run deploy:check
bunx wrangler login
bunx wrangler whoami
bun run deploy
```

`deploy:check` builds the site and runs Wrangler's dry run without publishing. `deploy` builds the site and uploads `dist/` to the `robotoken` Worker, including the current PDF in `public/files/`. It does not rebuild the LaTeX report; run `make -C ../report` first when the manuscript changes. Wrangler is pinned as a development dependency and recorded in `bun.lock`.

Use a Cloudflare account with the active `lbxa.net` zone. The custom-domain route in `wrangler.jsonc` connects `robotoken.lbxa.net`; Cloudflare manages its DNS and certificate when deployed. The Worker's `workers.dev` address is also enabled. See [Cloudflare's custom-domain documentation](https://developers.cloudflare.com/workers/configuration/routing/custom-domains/) if an existing DNS record conflicts with the route.

For CI, provide `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID` as secrets, then run `bun install --frozen-lockfile` and `bun run deploy`. For local use, `wrangler login` is a one-time setup; `wrangler whoami` confirms the account before publishing.
